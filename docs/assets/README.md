## Zasady dalszego porządkowania

1. Nie usuwać ani nie przenosić plików tylko na podstawie nazwy lub wieku.
2. Najpierw ustalić zawartość, autora/źródło, datę oraz to, czy dokument jest aktualny, historyczny czy roboczy.
3. Sprawdzić odwołania w README, dokumentacji, kodzie, stronach GitHub Pages i historii commitów. Wynik wyszukiwania kodu GitHub może być niepełny, więc brak trafienia nie dowodzi braku odwołań.
4. Dopiero po audycie zdecydować o przeniesieniu; dla publicznych linków do binariów trzeba uwzględnić, że stary adres może przestać działać.
5. Nie traktować ilustracji jako dowodu ani dokumentu historycznego jako aktualnej specyfikacji.

**Wynik tego etapu:** powstał spis materiałów i ich lokalizacji. Nie zmieniono żadnego pliku źródłowego ani binarnego.
