## Zasady porządkowania

1. Zachowuj oryginalne dokumenty, daty, wyniki i historię Git; nie poprawiaj retrospektywnie werdyktów.
2. Nowe historyczne podsumowania nazywaj `PODSUMOWANIE_PROJEKTU_RRRR-MM-DD.md` i dodawaj do indeksu.
3. Przy przenoszeniu plików sprawdzaj odnośniki względne zarówno w przeniesionym pliku, jak i w dokumentach odsyłających.
4. Duplikaty i pliki bez daty najpierw zinwentaryzuj; nie usuwaj ich automatycznie.
5. Rozróżniaj wynik historyczny, późniejszą korektę i aktualny stan projektu.
