# TIMDR-INFO-GEOMETRY — dziennik badań

**Status:** hipoteza badawcza, niepotwierdzona fizycznie. **Początek:** 2026-11-14. **Gałąź:** `research/info-geometry-2026-11`.

## Pytanie główne
Czy geometria przejść między stanami pozwala odzyskać dodatkową informację o dynamice sygnału, ponad klasyczne cechy i miary informacji?

## Dwa poziomy twierdzeń
1. **Operacyjny (testowalny):** zmiany krzywizny, skrętu i struktury trajektorii opóźnieniowej mogą pomagać wykrywać zmianę reżimu lub przewidywać przyszłe stany.
2. **Fundamentalny (spekulatywny):** elementarnym nośnikiem informacji dynamicznej mogłoby być rozróżnialne przejście między stanami. Nie zakładamy istnienia fizycznej „cząstki informacji” ani analogii z fotonem jako faktu.
