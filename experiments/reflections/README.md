# Eksperymenty — katalog tematyczny

Pliki źródłowe w tym katalogu są kanonicznymi lokalizacjami eksperymentów. Dotychczasowe ścieżki w katalogu `experiments/` pozostają jako cienkie punkty zgodności, aby nie zerwać starszych poleceń i importów.

Uruchamiaj skrypty z katalogu głównego repozytorium. Zależności i parametry są opisane w nagłówkach skryptów oraz odpowiednich workflow GitHub Actions.
