# TIMDR 51B.15e–k — checkpoint (2026-11-15)

Status: research notes, conditional mathematical results; not a claim of physical verification. Continuation of 51B.15a–d checkpoint.

## 51B.15e — geometric packing
For Q=[0,L]^d with sup metric and closed observation error balls radius eps>0, pairwise separation >2eps allows at most k^d codes, k=max(1,ceil(L/(2eps))). This packing number is sharp for a static code: a k-by-...-by-k grid with spacing L/(k-1)>2eps when k>=2. If k=1, only one code. For Euclidean metric a coarser cubical upper bound uses k=max(1,ceil(L sqrt(d)/(2eps))). Dimension lower bound d>=log2(M)/log2(k) when k>1. Error recurrence under K-Lipschitz F and per-step noise nu: r_n=K^n e0+nu sum_{j=0}^{n-1}K^j. It is an upper error estimate; robust separation >2r_n is sufficient, not universally necessary.

## 51B.15f — memory, stability, reversibility
For bi-Lipschitz F with Lip(F)<=K_+, Lip(F^{-1})<=K_-, K_-^{-n}d(x,y)<=d(F^n x,F^n y)<=K_+^n d(x,y). Exact reversibility does not imply noise-robust reconstruction. Any bound on lifetime depends on geometry, resolution, noise and dynamics. If k_n=max(1,ceil(L/(2r_n))) and r_n>0, M<=k_n^d is necessary for codes satisfying the sufficient pairwise separation >2r_n, not for every conceivable robust decoder.

## 51B.15g — relational reconstruction
Histories H_n, relational geometry G(h) defined as isomorphism class of explicitly selected signature (e.g. actual Next, Contains, Prec, MIN/MAX/Delta t). MIN/MAX are not presumed timestamps; Delta t need not equal MAX-MIN. Define observable z_n(h) and kappa_n^iso=max_z |{[G(h)] : z_n(h)=z}|. kappa=1 iff exact geometry determined by observation. For geometric code q(h) in normed cube, robust decoding under all closed eps-ball perturbations iff any pair with distinct geometries has distance >2eps. Define Delta_n^G=inf of these distances; for finite H_n robust iff Delta_n^G>2eps. CAUTION: for infinite H_n, Delta>2eps is sufficient but not necessary: every distinct-class distance may exceed 2eps while infimum equals 2eps. For fixed finite number M of geometry classes, capacity M<=k^d, sharp for static codes. Exact robust decoding of infinitely many distinct classes in bounded finite-dimensional cube with eps>0 impossible. Distinguish static geometry code from online update.

## 51B.15h — dynamical congruence
For history update T and geometry G, induced map Tbar on G(H) exists iff G(h)=G(h') implies G(Th)=G(Th'). Define h equiv_{G,T} h' iff G(T^j h)=G(T^j h') for all j>=0; this is coarsest T-congruence refining current geometry equivalence. For multiple event types use all admissible continuation words and termination semantics. Minimal predictive-relational state S_{G,T}=H/equiv. If finite, B_pred=ceil(log2|S|). For embedding rho and exact dynamics F rho=rho delta, global separation of distinct current geometry codes >2eps guarantees separation of ideal images, but not robustness to accumulated perturbations. Sufficient bound Delta_G>2(eps_obs+max_{0<=j<=N}r_j). Smooth autonomous flow time maps are injective, forcing delta injective when rho is injective.

## 51B.15i — regimes of reversibility
Global bijective extension with surjective pi and pi tilde_delta=delta pi implies delta surjective; for finite S it is bijective, and converse by trivial extension. One-step injective encoding s -> (delta(s),q(s)) requires |Q|>=max_y |delta^{-1}(y)|, achievable by labeling each fiber. For nonbijective finite delta, operational extension tilde S=S x Z, shift (s,k)->(s,k+1), Omega=S x N_0, pi_+(s,k)=delta^k(s) satisfies semiconjugacy on Omega only. No finite bijective extension with forward-invariant Omega and surjective pi_+ can realize nonbijective finite delta: finite permutation makes Omega fully invariant. For labeled branching histories H_n(y), exact reconstruction requires ceil(log2 max_y |H_n(y)|) auxiliary bits. In a deterministic finite state system without independent labels, complete n-step state history is fixed by initial state and this cost is bounded by ceil(log2|S|). Avoid claiming noninjectivity alone forces linear historical memory growth.

## 51B.15j — minimal relational reverse decoding
Let g:S->geometry classes. To reconstruct g(s) from (delta(s),q(s)), define r_G=max_y |{g(s):delta(s)=y}|. Minimal auxiliary alphabet cardinality is r_G, hence B_rel^(1)=ceil(log2 r_G)<=ceil(log2 max_y |delta^{-1}(y)|). For n-step initial geometry r_G(n)=max_y |{g(s):delta^n(s)=y}|. For whole intermediate geometry trajectory use distinct trajectories conditioned on delta^n(s)=y. In finite deterministic S all are bounded by |S|. A relationally decodable map need not be injective on full states. For noisy q with exactly known y, different geometries in same delta-fiber need separation >2eps. Capacity bound r_G<=k^d in sup cube.

## 51B.15k — dynamic relational compression
Let H subset A* be prefix-closed admissible event histories; Z:H->Zout the required relational output. Online encoder q:H->Q, update Phi(q(h),a)=q(ha), decoder D(q(h))=Z(h). If encoder also has to recognize which extensions are admissible, define h equiv_Z h' iff for all suffixes w: hw admissible iff h'w admissible, and when admissible Z(hw)=Z(h'w). This is a right congruence. The minimal number of exact online states is the number of equiv_Z classes (Myhill–Nerode style). Proof: same code must imply same outputs and extension availability; converse uses quotient, with optional rejecting sink for invalid continuations. For finite index m, minimum fixed-width state bits ceil(log2 m). If invalid continuations are externally disallowed and need not be recognized, a weaker equivalence may suffice; state the task precisely. Fixed window W of finite geometry alphabet m admits a shift buffer with at most m^W states and <=W ceil(log2 m) bits; exact reconstruction of all n independent binary geometric outputs needs >=n bits. Online finite memory depends on future relational distinguishability, not merely one-step reverse code r_G. Distinguish q_{t+1}=Phi(q_t,a_{t+1}) from Phi(q_t,s_{t+1}): the latter only suffices if next observed state retains all event distinctions required for updating.
